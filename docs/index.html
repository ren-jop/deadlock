Deadlock

a native macOS sleep-enforcement and distraction-blocking utility by Ren Jopson.

Highlights

• Scheduled sleep enforcement with IOKit wake handling
• Timed distraction blocking and settings friction
• Native Focus integration through local IPC
• Low-overhead event-driven daemon architecture

Built for a connected workflow

Planner handles planning and Apple Calendar integration, Focus runs the work session, and Deadlock provides distraction enforcement.
