Deadlock

A native macOS system that makes sleep windows and distraction rules difficult to ignore while keeping the enforcement layer event-driven and separate from the GUI.

What it does

A privileged daemon enforces scheduled sleep windows and responds to wake events without depending on the menu app staying open.

Distraction blocking is separate from the stricter adult-content protection policy, and Focus can activate distraction protection through local IPC.

The current build also includes an explicit one-day bypass that pauses enforcement until local midnight without deleting saved schedules.

AI in this project

AI is used heavily for debugging build errors, reasoning about daemon/UI boundaries, producing focused patch plans, reviewing IPC and state transitions, and maintaining detailed handoff documentation. Changes are validated against macOS behaviour, compile output and the working sleep mechanism.
