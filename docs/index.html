Deadlock

A privileged enforcement layer for sleep schedules and distraction policy. The menu-bar interface is a controller; the daemon remains authoritative.

Engineering problem

A focus rule is easy to ignore when enforcement disappears with the interface. Deadlock separates control from enforcement: the GUI edits policy, while a privileged daemon owns scheduling, sleep behaviour and web protection.

Design

IOKit wake handling, launchd lifecycle management and local Unix IPC keep the important behaviour outside the menu process. Focus can request distraction protection without becoming an owner of Deadlock state.

Website blocking uses managed hosts entries as the primary layer, with a browser-scoped Accessibility fallback for an already-open connection that survives a DNS change. With the weekly distraction schedule disabled, the configured domain list is enforced continuously; enabling the weekly schedule limits that baseline to the configured windows.

Install

Requires an Apple Silicon Mac, macOS 14+ and Apple's Command Line Tools.

git clone https://github.com/ren-jop/deadlock.git
cd deadlock
./install.sh

Web-blocking diagnostics

v1.2.3 corrects the IPv6 sink mapping, adds mobile hostname variants, rescans when protection starts and adds a browser-scoped fallback. ./deadlockctl web shows the owned hosts sections and resolver results.
