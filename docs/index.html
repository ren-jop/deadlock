Deadlock

A native macOS system that makes sleep windows and distraction rules difficult to ignore, while keeping the enforcement layer lightweight and event-driven.

Author
Ren Jopson
Version
v1.2.1
Source
GitHub

What it does

A root daemon enforces scheduled sleep windows and responds to wake events without depending on the GUI staying open.

A separate distraction policy can block selected websites during focus periods, while the menu app exposes status and deliberate override paths.

AI in this project

AI is used heavily for debugging build errors, reasoning about daemon/UI boundaries, producing focused patches, reviewing IPC/state transitions and maintaining detailed handoff documentation. Changes are still validated against macOS behaviour, compile output and the working sleep mechanism.
